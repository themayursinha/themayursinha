## Thesis

AI systems are moving from chatbots to agents.

Agents can:

- call tools
- read files
- send messages
- execute code
- access secrets
- modify infrastructure
- move money
- trigger workflows

That changes the security boundary.

The question is no longer only:

> Can the model say something unsafe?

The real question is:

> Can the system take an unsafe action?

My work focuses on deterministic controls at that boundary.
